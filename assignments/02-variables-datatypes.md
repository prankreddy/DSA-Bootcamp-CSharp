# Assignment 02 — Variables, Types & Operators

1. Declare variables of type `int`, `double`, `decimal`, `bool`, `string`, and `char`. Print them.
2. Take a user's salary as `decimal` and calculate 10% tax. Print the tax and net salary.
3. Write a program that checks if a year is a leap year.
4. Use the ternary operator to print "Positive", "Negative", or "Zero" for a given number.

**Important:** Always use `decimal` for money-related calculations.
