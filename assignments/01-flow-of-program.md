# Assignment 01 — Flow of Program & Basics

1. Write a program that prints "Hello, .NET" and asks for the user's name, then greets them.
2. Take two numbers as input and print their sum, difference, product, and quotient.
3. Write a program to check if a number is even or odd.
4. Create a simple menu-driven calculator (add, subtract, multiply, divide) that keeps running until the user chooses to exit.

**Bonus:** Explain in comments what happens when you run `dotnet build` vs `dotnet run`.
