# Complete C# / .NET + DSA Bootcamp Syllabus

## Phase 1 — Absolute Basics (C# Foundation)

1. What is .NET / CLR / JIT / Runtime
2. C# Basic Syntax & Top-level statements
3. Variables & Data Types (value vs reference, decimal for money)
4. Operators (arithmetic, logical, ternary, null-coalescing)
5. Conditions (if / switch expressions / pattern matching)
6. Loops (for, while, do-while, foreach)
7. Methods (parameters, return, overloading, optional params)
8. Namespaces & Assemblies

## Phase 2 — Object-Oriented Programming

9. Classes & Objects
10. Encapsulation
11. Inheritance
12. Polymorphism (virtual / override)
13. Interfaces
14. Abstract Classes
15. Static classes & members
16. Structs vs Classes
17. Records

## Phase 3 — Advanced C# Features

18. Delegates
19. Func, Action, Predicate
20. Lambda Expressions
21. Events
22. Extension Methods
23. Anonymous Types
24. Generics (List<T>, Dictionary, custom generics)
25. LINQ (Where, Select, GroupBy, OrderBy, etc.)
26. Async / Await
27. Task Parallel Library basics
28. Reflection & Attributes (intro)
29. IDisposable & using
30. Memory Management & GC (conceptual)

## Later Phases (DSA Focus — coming soon)

- Searching (Linear, Binary)

- Recursion & Backtracking

- Stacks & Queues
- Trees & BSTs
- Heaps
- Graphs
- Dynamic Programming
- And more...

---

**Learning Approach**

- Understand the concept deeply
- Type every example yourself
- Solve the assignments without looking at solutions first
- Build small mini-projects that combine topics
