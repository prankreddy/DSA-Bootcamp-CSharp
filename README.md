# DSA + Interview Preparation Bootcamp — C# / .NET

This is the C# / .NET version of the popular [DSA-Bootcamp-Java](https://github.com/kunal-kushwaha/DSA-Bootcamp-Java) by Kunal Kushwaha.

It follows the same progressive structure:
- Lectures with code samples
- Assignments (problems to solve)
- Clear topic-wise organization

## How to Use

1. Clone or download this repository
2. Open any lecture folder in VS Code / Visual Studio / Rider
3. Run the C# console projects or single files with `dotnet run`
4. Complete the corresponding assignments

## Structure

```
DSA-Bootcamp-CSharp/
├── assignments/          # Problem statements (solve these)
├── lectures/             # Code samples organized by topic
│   ├── 01-intro-to-dotnet-and-csharp/
│   ├── 02-variables-datatypes/
│   ├── 03-operators-conditions-loops/
│   ├── 04-methods/
│   ├── 05-oop-basics/
│   └── 06-advanced-csharp/
├── README.md
└── SYLLABUS.md
```

## Prerequisites

- .NET 6 or later SDK installed
- Basic understanding of programming concepts

## Next Steps

Start with `lectures/01-intro-to-dotnet-and-csharp` and work through the topics in order.
